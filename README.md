# SIAS Centinela Desmovilización

Repositorio de trabajo para el análisis de datos del proyecto SIAS Centinela Desmovilización.

## Estructura

- `Notebook/`: notebooks de análisis y exploración.
- `.vscode/`: configuración compartida del entorno de desarrollo.

## Primeros pasos

1. Abra el repositorio en Visual Studio Code.
2. Seleccione el entorno Conda que utilizará para el proyecto.
3. Abra `Notebook/001.ipynb` y seleccione el kernel correspondiente.
